STILLWATER RIG ASSISTANT — Version 1\n\nThis is a working offline-capable starter PWA. It currently uses built-in starter recommendations, NOT your live Google Sheets.\n\nTo install on Android, host these files on an HTTPS website (e.g. GitHub Pages), visit that URL in Chrome while online, and use Chrome menu > Add to Home screen / Install app. Open once online to cache files. Then test in airplane mode. Opening index.html directly from a ZIP or local file does NOT install the service worker.\n\nNext development step: connect the existing Google Sheet via a safely published read-only data endpoint and cache the latest dataset offline.\n
